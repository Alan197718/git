## 复用的推送技巧（无 gh、无已存凭证）

1. 先 `git ls-remote "https://x-access-token:<TOKEN>@github.com/<owner>/<repo>.git"` 验证令牌+连通性（空仓库会无输出且退出码 0）。
2. `git remote set-url origin https://x-access-token:<TOKEN>@github.com/<owner>/<repo>.git` → `git push -u origin main`。
3. 推送后务必 `git remote set-url origin https://github.com/<owner>/<repo>.git` 还原，避免令牌留在 config。
